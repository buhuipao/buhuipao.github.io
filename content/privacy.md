本说明适用于不会跑（blog.buhuipao.com）及其 GitHub Pages 镜像。本站是公开的静态技术博客，不提供本站用户注册或在线付款。

## 访问与统计

网站由 Cloudflare Pages 和 GitHub Pages 提供托管，页面使用 Google Analytics 进行访问统计，主站也使用 Cloudflare Web Analytics。浏览页面时，相关服务可能接收 IP 地址、浏览器信息、访问时间、来源页面及所访问的地址。Google Analytics 可能通过 Cookie 区分访问并统计使用情况。

服务方的数据处理方式可查看 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)、[GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)和 [Google 隐私政策](https://policies.google.com/privacy)。

## Google 广告

本站申请使用 Google AdSense，是否实际展示广告取决于网站审核及页面配置。启用广告的页面可能由 Google 或其广告合作伙伴使用 Cookie，根据您之前对本网站或其他网站的访问展示广告。第三方也可能使用网络信标或 IP 地址等信息投放、衡量广告，或防止欺诈。

您可以在 [Google 广告设置](https://myadcenter.google.com/)管理个性化广告偏好，也可以访问 [aboutads.info](https://www.aboutads.info/choices/)了解参与服务的第三方个性化广告退出选项。关闭个性化广告并不意味着完全不再显示广告。Google 如何使用合作网站中的信息，参见 [Google 的合作伙伴网站数据说明](https://policies.google.com/technologies/partner-sites)。

## 评论与外部链接

部分文章使用 Disqus 评论。加载评论或使用 Disqus 登录时，Disqus 可能接收浏览信息并使用 Cookie；提交的评论、显示名称等可能公开展示。请查看 [Disqus 隐私政策](https://disqus.com/privacy-policy/)，并通过其提供的功能管理评论和账户信息。

文章可能引用 GitHub、LeetCode 等外部网站，头像和字体也可能由第三方提供。加载这些资源或点击链接时，相关服务会收到网络请求，并按各自的隐私政策处理数据。

## 您可以控制什么

您可以在浏览器中清除或限制 Cookie，使用 [Google Analytics 退出工具](https://tools.google.com/dlpage/gaoptout)，并在相应的第三方服务中调整隐私设置。限制第三方资源可能影响统计、广告或评论功能。

如对本站内容或隐私说明有疑问，请通过[关于与联系](/about/)提供的渠道反馈。公开的问题页和评论区不适合提交敏感个人信息。
