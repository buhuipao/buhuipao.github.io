这里记录 Python、Linux 和算法实践。教程从一个具体问题出发，解释选择一种实现的原因，并用小例子检查边界条件。

从这些教程开始

  • 用 bisect 查询时间窗口：重复时间戳和左右边界怎样影响结果，二分查找为什么不等于快速插入。
  • 最长递增子序列：从动态规划到二分查找：推导状态、逐步跟踪数组变化，并检查重复元素和空输入。
  • 最小栈：重复最小值为什么不能漏记：从一个会出错的操作序列理解辅助栈的不变量。
  • fork 后哪些状态独立，哪些仍然共享：用一个单线程实验区分内存副本、文件偏移和子进程回收。
